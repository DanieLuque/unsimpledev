# 📌 Proyecto destacado

## 🌿 Lichen Dreams

**"Lee el aire, entiende tu entorno"**

Lichen Dreams es un proyecto desarrollado para analizar la calidad del aire utilizando líquenes como bioindicadores.

### 🔧 Tecnologías utilizadas

* **Frontend:** Flutter
* **Backend:** Python + FastAPI
* **Base de datos:** MySQL / MariaDB
* **Autenticación:** JWT
* **API:** REST
* **Documentación:** Swagger / OpenAPI
* **Mapas:** Google Maps
* **ORM:** SQLAlchemy
* **Control de versiones:** Git + GitHub
* **Despliegue y entorno:** Docker / Linux

### 💻 Mi participación

Mi principal responsabilidad dentro del proyecto está relacionada con el **Backend**, trabajando en:

* Desarrollo y mantenimiento de APIs REST.
* Implementación de endpoints.
* Integración del backend con la base de datos.
* Persistencia de análisis.
* Gestión de autenticación y sesiones.
* Implementación de consultas y resultados de análisis.
* Corrección de errores del backend.
* Trabajo con SQLAlchemy.
* Pruebas de endpoints mediante Swagger.
* Integración entre backend y frontend.
